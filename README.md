# NOAIDI

Статичний сайт української сторінки NOAIDI за переданим концептом.

## Структура

- `index.html` — головна сторінка
- `styles.css` — адаптивний editorial-дизайн
- `script.js` — мобільне меню
- `assets/` — оригінальні фото інструмента
- `PROJECT_PROFILE.md` — пам'ять проекту, SEO-чеклист і правила для наступних правок

У видимому тексті сайту використано термін `бубен`.
